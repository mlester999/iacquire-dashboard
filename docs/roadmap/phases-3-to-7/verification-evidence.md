* The real language model was never contacted, so reply quality, the price-grounding rule and the instruction-leak rule are tested against stubs only.
* No Hermes runtime, no calendar booking through chat (the native-calendar path is not exercised by chat), no real provider message, no real browser other than the in-app browser pane.
* The Website Studio site path (script injection and CSP on a published site) is covered by tests and the migration rehearsal's role checks, but was not loaded in a browser.
* Automation Studio's editor was not opened to check the five new triggers' labels.
* Hosted migrations, deploy, scheduler: none done. The `webChatRetention` job has never run outside tests.
* The pane's mobile emulation reports a stale `innerWidth` after navigation; layout was judged from `clientWidth`, element boxes and clipping ancestors, which showed no page content wider than 375 px.
