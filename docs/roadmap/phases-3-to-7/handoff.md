## Traps learned (each cost time)

* A same-origin native form post from a page served with `Referrer-Policy: no-referrer` arrives with `Origin: null`; use `src/server/security/same-site.ts`, never read `Origin` alone (the customer's proposal and invoice forms answered "Not allowed." in a browser while every test passed).
* A server page must not call a function or constant exported from a `"use client"` file (it crashed `/invoices/new`); put it in a plain `src/lib` file. A file under `src/lib` that a client component imports must not read `node:*` (it broke the clean build). `tests/client-bundle-safety.test.ts` guards both; run it alone, it timed out under a full run once.
* The default Turbopack build cannot resolve `next` through this worktree's `node_modules` junction: build with `node scripts/build-clean.mjs --webpack` (through `run-locked.mjs heavy`).
* Seeds and QA scripts must compute dates in the workspace's time zone (`todayIn`), not with `toISOString().slice(0, 10)` (UTC); the invoice QA seed was wrong that way until `2e192a1`.
* Shell heredocs and `sed` strip backslashes; the Edit tool turns a typed backslash-u escape into the literal character (a regex once contained raw U+2028 and U+2029): use `String.fromCharCode` in tests and re-read every regex. The Write tool can flip line endings: `python -I scripts/eol-scan.py <base> WORKTREE` (`--fix` repairs). All files in this folder are LF.
* `withSystem` cannot be nested in tests. The database allows one agency workspace. A phone number or email used in a test must be unique within the process. A vitest worker-start timeout can mark a full run exit 1 while every test passes: rerun the file, then the suite.
* Do not edit the tree while a vitest or build run is in progress; heavy commands go through `node scripts/run-locked.mjs`.
* A test may not open a socket to another machine (`tests/support/no-network.ts`); the one slip before that guard was about five 401 answers from `api.paymongo.com`.
* The rehearsal ran once after the last edit of 0087 to 0095; anything that touches them needs it again.
