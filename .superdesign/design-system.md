# iAcquire · Command workspace

Preserve the real iAcquire logo and six existing employee mascot assets. Use Geist for the
interface and Geist Mono for compact technical identifiers; Instrument Serif is a selective
editorial accent. Titles have deliberate tight tracking, but body text remains readable.

Electric blue anchors action and navigation. Indigo/violet identifies AI capabilities, green
requires successful verification, amber denotes limited/unverified attention, and red signals
failure. Neutral status is visibly different from credentials saved. Pair every color with text
and an icon. Keep existing WCAG-oriented light and dark text tokens.

Use a dark navigation rail with grouped collapsible destinations and an optional compact mode.
Contextual headers include breadcrumbs, navigation search and theme controls. White, tinted and
dark panels serve different purposes. Compose modules as role maps, galleries, timelines,
queues, workflow phases and split panes rather than repeated large cards.

Motion uses 160/240/420ms timing and a restrained spring for drawers. Enter sections with a short
stagger, animate genuine progress and preserve streaming/tool indicators only while real jobs
run. All motion respects reduced-motion preferences. Mobile controls have usable tap targets,
dialogs fit the viewport and content wraps instead of clipping.

Every metric, chart and active connection derives from real records. Synthetic QA is labeled.
Missing project media receive tasteful explicit placeholders; no stock image represents work.
Preserve all backend permissions, prices, provider contracts and publication review gates.
